# Food & Beverage AI Copilot Interactivo

App demo para alimentos y bebidas con dashboards operacional, financiero, ejecutivo y comercial, preguntas dinámicas por perfil, respuestas didácticas, datos simulados con movimiento y simuladores SAP MII, ME, CAP y BTP.

## Ejecutar
```bash
pip install -r requirements.txt
python app.py
```
Abrir: http://127.0.0.1:5000
