# Guía de ejecución

## Local
1. Descomprimir el ZIP.
2. Entrar a `Food_Beverage_AI_Copilot_Interactivo`.
3. Ejecutar `pip install -r requirements.txt`.
4. Ejecutar `python app.py`.
5. Abrir `http://127.0.0.1:5000`.

## Celular
Conectar el computador y celular a la misma red WiFi. Buscar la IP del computador y abrir `http://IP:5000`.

## Nube
Usar Render, Railway o Docker con `python app.py` y puerto 5000.
